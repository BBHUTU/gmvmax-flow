账户余额监控

每天自动检查两个广告账户还剩多少钱、能撑几天，不够了提前提醒充值

已上线 · 每日 09:27 播报
适用范围：及时监控并提醒 TikTok 广告后台余额，防止余额不足导致投放中断。
流程逻辑
  1. 读取账户余额自动拉取 US 和 MX 两个广告账户的当前余额
  2. 算日均消耗取近 7 天的平均每天花多少钱
  3. 算安全线日均消耗 × 16 天；遇到周末、节假日自动上浮，多留余量
  4. 判断是否够余额低于安全线就判定为不足
  5. 推送播报每天发余额日报；不足时额外告警，直接给出还能撑几天、建议充多少
功能参数
监控对象US-DrBioCare、MX-BioCare 两个账户（USD）
播报时间每日 09:27 自动发送，无需人工触发
告警规则余额 < 近 7 天日均消耗 × 16 天
告警内容剩余余额、可支撑天数、建议充值金额
送达方式飞书机器人推送
实际运行截图
TikTok 每日余额播报：US 余额充足 / MX 余额不足并给出建议充值金额

GMV Max 数据流

从 TikTok 后台自动导出，到底表沉淀，再到日报 / 周报自动推送

已上线 · 每日执行
适用范围：每日自动导出 GMV Max 数据、沉淀成台账，并基于台账自动生成日报与周报，全程无需手动汇总。
🚀
TikTok 后台
定时读取 GMV Max 原始数据
⚙️
自动导出
美区 / 墨区双账号并行处理
🗂️
飞书底表
按天累积形成标准化台账
📊
日报 / 周报
自动汇总、计算 ROAS 并推送
流程逻辑
  1. 每日自动导出定时拉取美区 DrBioCare 和墨区 BIOCARE 的 GMV Max 数据
  2. 整理写入底表按字段格式对齐后追加到《GMVMAX后台数据》表，形成按天累积的台账
  3. 生成日报每天下午读取当日数据，按品类自动归类、计算 ROAS，推送到业务群
  4. 生成周报每周一汇总上周一至周日数据，给出市场总览和品类拆解
  5. 异常处理当天无数据或品类未匹配时自动跳过，并如实报告
功能参数
数据来源TikTok 广告后台 GMV Max（含 VSA 数据）
覆盖账号美区 DrBioCare + 墨区 BIOCARE，双账号并行
写入位置飞书《GMVMAX后台数据》表格
日报推送每天下午自动发送当日 GMV / 消耗 / ROAS
周报推送每周一汇总上周全量数据
送达方式飞书机器人推送到业务群
实际运行截图
每日导出结果：美区 1 条 / 墨区 5 条，VSA 无数据自动跳过
日报样例：10 月月度累计 + 当日美区 / 墨区明细
周报样例：墨区总消耗、总 ROAS 及牙贴 / 泡腾片 / 牙膏拆解

创意脚本读取

把视频链接自动变成中英对照脚本，人只需要把链接填进表格

已上线 · 有链接就自动触发
适用范围：批量提取 TikTok 竞品/精品视频的中英对照脚本，用于素材库沉淀和二次创作参考。
流程逻辑
  1. 填链接在飞书「脚本读取」表 A 列入 TikTok 视频链接（全流程唯一要人动手的一步）
  2. 自动触发表格里一有新链接就自动开始跑，不用等定时、不用人点
  3. 抓视频逐个打开链接，把视频内容抓下来
  4. 转写原文把口播内容转成文字，写回同一行的 B 列「原文提取」
  5. 翻译输出自动生成中文，写回同一行的 C 列「译文」
  6. 推送通知提取完成后发结果通知：待处理 / 成功 / 失败 / 写回单元格数
功能参数
输入飞书表格 A 列的视频链接
处理视频采集 → 脚本转写 → 翻译
输出同行 B 列原文、C 列译文，链接和脚本对得上
触发方式有新链接就自动触发，云端执行，不依赖电脑开机
失败处理失败行会在下次运行时自动重试
送达方式完成后飞书机器人推送
实际运行截图
脚本读取结果：A 列原链接，B 列英文原文，C 列中文翻译
提取完成通知：96 行待处理，67 行成功，失败行自动重试
把重复的事情交给自动化，人工只负责决策和异常处理
